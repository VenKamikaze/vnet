# vnet

Virtual UDP networking for games: a small, non-blocking C datagram API with pluggable backends, plus a relay server so browser builds (WebSocket/WebTransport) and native clients can share a virtual LAN.

**Status:** planning. Nothing is implemented yet. See [`doco/README.md`](doco/README.md) for the work briefs and design decisions.
